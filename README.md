# Домашняя работа №3 — преобразование Хафа

Подбор параметров `cv.HoughCircles` для семи изображений и подсчёт окружностей.
Используется `HOUGH_GRADIENT_ALT` (вариант преобразования Хафа из OpenCV).

```bash
python -m pip install -r requirements.txt
python main.py
```

- `hw3/` — исходные изображения.
- `parameters.json` — параметры для каждого изображения: область поиска,
  размер, радиусы, расстояние между центрами и порог `param2`.
- `results/` — изображения с нумерацией, `counts.txt`, `counts.csv` и координаты `circles.csv`.

Для разных размеров труб используются два диапазона радиусов; близкие повторные
детекции объединяются. На `logs-4` изображение растягивается по горизонтали
перед поиском; окружности отображаются обратно как эллипсы.
Области поиска исключают фон и квадратные трубы на `logs-3`.

Количество — результат алгоритма. Из-за перспективы, перекрытий, годичных колец
и неровных торцов остаются пропуски и ложные срабатывания. Вложенные трубы могут
обнаруживаться отдельно; несколько краёв одного отверстия могут давать дубликаты.
Это не гарантированное точное число всех предметов.
